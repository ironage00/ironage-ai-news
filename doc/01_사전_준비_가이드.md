## 1. Python 3.11 이상 설치

Python은 이 시스템의 핵심 언어입니다. 이미 설치되어 있다면 버전 확인 후 건너뛰세요.

### 설치 여부 확인

명령 프롬프트(cmd) 또는 PowerShell에서:

```
python --version
```

`Python 3.11.x` 또는 `Python 3.12.x` 이상이 표시되면 완료.  
그렇지 않으면 아래 방법으로 설치합니다.

### Windows 설치 방법

1. https://www.python.org/downloads/ 접속
2. "Download Python 3.12.x" 버튼 클릭
3. 설치 파일 실행
4. **중요**: 설치 화면 맨 아래 `☑ Add Python to PATH` 반드시 체크
5. "Install Now" 클릭
6. 설치 완료 후 cmd 재시작 → `python --version` 재확인

## 2. Git 설치

Git은 코드 관리 도구입니다. GitHub에서 코드를 내려받을 때 사용합니다.

### 설치 여부 확인

```
git --version
```

`git version 2.xx.x` 표시되면 완료.

### Windows 설치 방법

1. https://git-scm.com/download/win 접속
2. "Click here to download" 클릭하여 설치 파일 다운로드
3. 설치 중 모든 옵션은 기본값 그대로 "Next" 클릭
4. 설치 완료 후 cmd 재시작 → `git --version` 재확인

---

## 3. GitHub 계정 + 저장소 Fork

GitHub는 코드를 저장하고 자동 실행(Actions)하는 공간입니다.

### 계정 생성

1. https://github.com 접속 → "Sign up" 클릭
2. 이메일(업무용 권장), 비밀번호, 사용자명 입력
3. 이메일 인증 완료

### 저장소 Fork (복사)

이미 완성된 코드를 내 계정으로 가져옵니다.

1. 원본 저장소 접속: `https://github.com/ironage00/ironage-ai-news`
2. 오른쪽 상단 **Fork** 버튼 클릭
3. "Create fork" 클릭
4. 내 계정에 `ironage-ai-news` 저장소가 생성됨

> **Fork란?** 원본 코드를 내 계정으로 복사하는 것.  
> 이후 내 저장소에서 독립적으로 설정하고 운영합니다.

## 4. Google 계정

Gmail 발송과 Google Docs/Drive 연동에 사용됩니다.

### TTA 임직원(@tta.or.kr) 반드시 읽어야 할 주의사항

> TTA 업무 이메일(`이름@tta.or.kr`)은 Google Workspace(기업용 구글) 계정입니다.  
> 이 시스템의 OAuth2 인증(Google Drive/Docs 연동)은 **개인 Gmail**(`이름@gmail.com`)로  
> 진행해야 합니다.

이유: Google Workspace 계정은 조직 관리자(TTA IT)가 외부 앱 접근을 통제하며,  
별도 허용 없이는 `@tta.or.kr` 계정으로 OAuth2 인증 시 차단될 수 있습니다.

```
역할 구분
───────────────────────────────────────────────
OAuth2 인증 (Google Drive 연결)  →  개인 Gmail (@gmail.com)
보고서 발송·수신                 →  업무 메일 (@tta.or.kr)
보고서 열람                      →  이메일 링크 클릭 → @tta.or.kr로 열람 가능
```

**준비**: 개인 Gmail 계정(`이름@gmail.com`)이 없다면 미리 하나 만들어 두세요.

### Gmail 앱 비밀번호 설정 (나중에 필요, 미리 확인)

일반 Gmail 비밀번호가 아닌 **앱 비밀번호**가 필요합니다.  
(이유: 2단계 인증 + 앱 접근 보안)

이메일 발송용 Gmail은 개인 Gmail을 사용하거나,  
IT 부서에서 별도 발송 전용 계정을 만들어 사용하는 것을 권장합니다.

설정 방법은 **02_API키_발급_상세가이드.md**의 'Gmail 앱 비밀번호' 섹션에서 설명합니다.

## 5. Supabase 계정 + 프로젝트 생성

Supabase는 기사 데이터를 저장하는 클라우드 데이터베이스입니다.

### 계정 생성

1. https://supabase.com 접속 → "Start your project" 클릭
2. "Sign Up with GitHub" 클릭 (GitHub 계정 연동 — 가장 간편)
3. GitHub 계정 승인

### 프로젝트 생성

1. 로그인 후 "New project" 클릭
2. 설정 입력:
   - **Name**: `tta-ai-news` (또는 원하는 이름)
   - **Database Password**: 안전한 비밀번호 설정 (반드시 기록해 두세요)
   - **Region**: `Northeast Asia (Seoul)` 선택 → 속도 유리
3. "Create new project" 클릭
4. 프로젝트 생성까지 약 1~2분 대기

### 연결 문자열 확인 (나중에 필요)

1. 좌측 메뉴 → **Settings** → **Database**
2. **Connection string** 섹션 → **URI** 복사
3. 형식: `postgresql://postgres:[YOUR-PASSWORD]@db.xxxx.supabase.co:5432/postgres`
4. 메모장에 임시 저장

## 7. 네이버 개발자 계정 + 오픈 API 신청

국내 ICT 뉴스 수집에 네이버 뉴스 API를 사용합니다.

### 신청 방법

1. https://developers.naver.com 접속
2. 우상단 "로그인" → 네이버 계정으로 로그인
3. 상단 메뉴 **Application → 애플리케이션 등록** 클릭
4. 입력 사항:
   - **애플리케이션 이름**: `TTA AI News` (자유)
   - **사용 API**: `검색` 체크
   - **환경**: `WEB 설정` → 서비스 URL: `http://localhost`
5. 등록 완료 후 **Client ID**와 **Client Secret** 확인 → 기록

## 8. OpenAI 계정 + API 키

AI 분석(기사 필터링·요약·인사이트 도출)의 핵심 서비스입니다.

### 계정 생성

1. https://platform.openai.com 접속 → "Sign up"
2. 이메일 인증 완료
3. 전화번호 인증 (필수)

### API 키 발급

1. 로그인 후 우상단 계정 아이콘 → **API keys** 클릭
2. "Create new secret key" 클릭
3. 이름 입력 (예: `TTA-News-System`)
4. 생성된 키(`sk-...`)를 **반드시 즉시 복사해 안전한 곳에 저장**
   - 이 화면에서 한 번만 표시됩니다. 창을 닫으면 다시 볼 수 없습니다.

### 결제 수단 등록 (필수)

OpenAI API는 사용량 과금 방식입니다. 사용하려면 카드 등록이 필요합니다.

1. 좌측 메뉴 → **Billing** → "Add payment method"
2. 신용카드 정보 입력
3. 초기 크레딧 $5 충전 권장 (약 7,000원 — 수개월 사용 가능)

> **비용 안내**: GPT-4o 기준 기사 1건 분석에 약 0.02~0.05달러.  
> 하루 50건 분석 시 월 약 30~75달러 → 실제로는 더 저렴 (필터링 후 소량만 분석).  
> 실제 운영 시 월 5,000~15,000원 수준으로 예상됩니다.
