**대상**: API 키 발급을 마친 담당자  
**목적**: 코드를 로컬 PC에 설치하고, 기본 설정을 완료해 첫 실행까지 확인


## ① 코드 내려받기

GitHub에서 Fork한 저장소를 로컬 PC로 복사합니다.

PowerShell 또는 명령 프롬프트(cmd)를 열고:

```bash
# 작업 폴더로 이동 (원하는 위치 선택)
cd C:\Users\본인계정\Documents

# 저장소 복사 (YOUR-GITHUB-ID를 본인 GitHub 아이디로 교체)
git clone https://github.com/YOUR-GITHUB-ID/ironage-ai-news.git

# 폴더 진입
cd ironage-ai-news
```

> Fork를 안 했다면 원본에서 직접 clone해도 됩니다:  
> `git clone https://github.com/ironage00/ironage-ai-news.git`

---

## ② Python 패키지 설치

프로젝트에 필요한 라이브러리를 모두 설치합니다.

```bash
pip install -r requirements.txt
```

설치 중 오류가 나면:

```bash
# pip 업그레이드 후 재시도
python -m pip install --upgrade pip
pip install -r requirements.txt
```

설치 완료 확인:

```bash
python -c "import streamlit, openai, sqlalchemy; print('OK')"
```

`OK`가 출력되면 성공.

### Google Alerts RSS URL 만드는 방법

Google Alerts는 특정 키워드 뉴스를 RSS 피드로 받는 서비스입니다.

1. https://www.google.co.kr/alerts 접속
2. 검색어 입력 (예: `6G 표준화`)
3. "옵션 보기" 클릭
4. 게재 빈도: `실시간`
5. 소스: `뉴스`
6. 언어: `한국어` 또는 `모든 언어`
7. 지역: `한국` 또는 `모든 지역`
8. 전송 대상: `RSS 피드` 선택
9. "알림 만들기" 클릭
10. 생성된 알림 옆 RSS 아이콘(주황색) 클릭 → URL 복사

이 URL을 `google_alerts_rss` 배열에 추가합니다.

## ④ .env 파일 작성 (Supabase 연결)

Supabase 클라우드 DB 연결 정보는 `.env` 파일에 별도로 관리합니다.

프로젝트 루트(최상위 폴더)에 `.env` 파일 생성:

```
DATABASE_URL=postgresql://postgres:비밀번호@db.프로젝트ID.supabase.co:5432/postgres
```

예시:
```
DATABASE_URL=postgresql://postgres:mypassword123@db.abcdefgh.supabase.co:5432/postgres
```

> `.env` 파일은 `.gitignore`에 포함되어 있어 GitHub에 자동으로 올라가지 않습니다.  
> 절대 커밋하지 마세요.

## ⑥ DB 초기화 및 테스트 실행

```bash
python news_engine.py test
```

처음 실행 시:
1. 브라우저가 열려 Google 계정 선택 화면 표시
2. 업무용 Gmail 계정 선택
3. 권한 허용 (Docs + Drive 접근)
4. 브라우저 닫고 터미널로 돌아옴

성공 출력 예시:

```
[DB] 테이블 초기화 완료
[DB] 전체 기사: 0건 (초기 상태)
[DB] 오늘 수집: 0건
[CONFIG] OpenAI 키 확인: sk-proj-...
[CONFIG] 네이버 API 확인: OK
[CONFIG] Gmail 설정 확인: OK
```

오류가 나면 **06_운영_및_장애처리.md**의 문제 해결 섹션을 참고하세요.

## ⑦ 첫 수집 테스트

실제 뉴스 수집을 한 번 실행해 봅니다.

```bash
python news_engine.py daily
```

실행 중 로그 예시:

```
[수집] Google Alerts RSS 처리 중... (15개 소스)
[수집] 네이버 뉴스 검색 중... ("5G", "6G", ...)
[필터] AI 품질 필터링 중... 342건 → 상위 68건 선별
[DB] 신규 기사 저장: 68건 (중복 12건 제외)
[분석] AI 심층 분석 시작... (68건)
[분석] 완료: 68건 분석 결과 저장
[이메일] 일일 보고서 발송 완료 → you@example.com
```

수집 완료 후:
- 설정한 이메일 주소로 일일 보고서 이메일 수신 확인
- Google Drive에 보고서 문서 생성 확인

## ⑧ 웹 대시보드 실행

```bash
streamlit run main_app.py
```

실행 후 브라우저에서 자동으로 http://localhost:8501 열림.

대시보드에서 확인할 것:
- 상단 통계 카드에 수집된 기사 수 표시 여부
- 뉴스 현황 탭에서 기사 목록 확인
- AI 검색 탭에서 질문 입력 → 답변 확인

대시보드 종료: 터미널에서 `Ctrl + C`

```

├── trend_analyzer.py       ← 트렌드 분석
├── requirements.txt
└── data/
    ├── config.json         ← (직접 생성) API 키 및 설정
    ├── news.db             ← (자동 생성) 로컬 SQLite
    └── logs/
        └── ironage_YYYYMMDD.log
```
