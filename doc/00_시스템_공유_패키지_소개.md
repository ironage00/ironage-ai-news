## 이 문서는 무엇인가요?

본 패키지는 **TTA 표준화본부 이동통신표준팀**이 자체 개발한 AI 뉴스 인텔리전스 시스템을  
TTA 내 다른 부서·연구소에서도 활용할 수 있도록 정리한 공유 가이드입니다.

기술적 배경이 없는 담당자도 이 문서 묶음만 따라가면 **우리 부서에 맞춤화된 뉴스 분석 시스템**을  
직접 구축·운영할 수 있도록 단계별로 설명합니다.

---

## 배경과 개발 동기

### 문제: 정보 과부하 속의 수작업

ICT·통신 분야 연구 업무를 수행하는 연구원은 매일 수백 건의 뉴스·보도자료·표준화 동향을  
직접 검색·읽고·정리해야 합니다. 이 과정은 다음과 같은 문제를 안고 있었습니다.

| 문제 | 구체적 상황 |
|------|-----------|
| 시간 소모 | 하루 1~2시간 뉴스 수집·정리에 소비 |
| 누락 위험 | 검색어를 놓치면 중요 이슈가 보고에서 빠짐 |
| 비일관성 | 담당자가 바뀌면 정리 방식이 달라짐 |
| 분석 부재 | 기사 나열에 그쳐 트렌드·시사점 도출 어려움 |

### 해결: AI가 수집·분석·보고를 자동화

IRONAGE AI Analytics System은 이 모든 과정을 자동화합니다.

```
사람이 하던 일             →    시스템이 대신
───────────────────────────────────────────────
뉴스 검색 (매일)           →    Google Alerts + 네이버 API 자동 수집
관련 기사 판별             →    GPT-4o가 관련도 점수화 → 상위 20% 선별
기사 요약 및 키워드 추출   →    AI 심층 분석 자동 실행
보고서 작성                →    Google Docs 자동 생성 + Gmail 자동 발송
트렌드 파악                →    지식 그래프 + 급등 키워드 시각화
```

담당자는 매일 아침 **이메일 한 통**으로 전날 주요 동향을 파악하고,  
필요할 때 **웹 대시보드**에서 심층 검색·분석을 수행합니다.

## TTA 조직 구성 및 활용 현황

TTA는 현재 아래 6개 본부·연구소로 구성되어 있습니다.

| 조직 | 주요 업무 | 시스템 현황 |
|------|---------|-----------|
| **미래전략기획실** | ICT 정책·전략 수립, 대외 협력 | 적용 가능 |
| **표준화본부** | ICT 국제표준 제안·표준화 활동 | ✅ **현재 운영 중** |
| **AI통신융합연구소** | AI·5G/6G 기술 연구 및 시험 | 적용 가능 |
| **AI기반기술연구소** | 인공지능 원천 기술 연구·평가 | 적용 가능 |
| **AX/SW연구소** | 디지털 전환, 소프트웨어 품질 | 적용 가능 |
| **정보보호안전연구소** | 사이버보안, 개인정보보호, 인증 | 적용 가능 |

각 조직은 동일한 시스템을 **독립적으로 구축**하여 해당 분야 맞춤 키워드로 운영합니다.

## 시스템이 해주는 것

### 매일 자동으로 (오전 9시)
- Google Alerts RSS + 네이버 뉴스 API에서 최신 기사 수집
- 관련도 AI 필터링 → DB 저장
- 기사별 AI 분석(요약·키워드·시사점) 자동 실행
- 팀/연구소별 맞춤 보고서 → Gmail 발송 + Google Docs 저장

### 매주 자동으로 (월요일 오전 9시)
- 지난 7일 핵심 이슈·트렌드 종합 주간 리포트 발송

### 언제든지 (웹 대시보드)
- 수집 기사 키워드 검색 및 AI 분석 결과 열람
- 자연어 질문 → AI 답변 (RAG 기반)
- 기업·기술·국가 간 연관 관계 지식 그래프 탐색
- 급등 키워드 실시간 알림 확인
