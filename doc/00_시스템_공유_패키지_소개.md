# IRONAGE AI Analytics System — 공유 패키지 소개서

**TTA AI리더그룹 표준화본부 이동통신표준팀**
최초 작성: 2026-06-11 | 버전: v5.0

---

## 이 문서는 무엇인가요?

본 패키지는 **TTA 표준화본부 이동통신표준팀**이 자체 개발한 AI 뉴스 인텔리전스 시스템을  
TTA 내 다른 본부·팀에서도 활용할 수 있도록 정리한 공유 가이드입니다.

기술적 배경이 없는 담당자도 이 문서 묶음만 따라가면 **본인 본부에 맞춤화된 뉴스 분석 시스템**을  
직접 구축·운영할 수 있도록 단계별로 설명합니다.

---

## 배경과 개발 동기

### 문제: 정보 과부하 속의 수작업

ICT·통신 분야 표준화 업무를 수행하는 연구원은 매일 수백 건의 뉴스·보도자료·표준화 동향을  
직접 검색·읽고·정리해야 합니다. 이 과정은 다음과 같은 문제를 안고 있었습니다.

| 문제 | 구체적 상황 |
|------|-----------|
| 시간 소모 | 하루 1~2시간 뉴스 수집·정리에 소비 |
| 누락 위험 | 검색어를 놓치면 중요 이슈가 보고에서 빠짐 |
| 비일관성 | 담당자가 바뀌면 정리 방식이 달라짐 |
| 분석 부재 | 기사 나열에 그쳐 트렌드·시사점 도출 어려움 |

### 해결: AI가 수집·분석·보고를 자동화

IRONAGE AI Analytics System은 이 모든 과정을 자동화합니다.

```
사람이 하던 일             →    시스템이 대신
───────────────────────────────────────────────
뉴스 검색 (매일)           →    Google Alerts + 네이버 API 자동 수집
관련 기사 판별             →    GPT-4o가 ICT 관련도 점수화 → 상위 20% 선별
기사 요약 및 키워드 추출   →    AI 심층 분석 자동 실행
보고서 작성                →    Google Docs 자동 생성 + Gmail 자동 발송
트렌드 파악                →    지식 그래프 + 급등 키워드 시각화
```

담당자는 매일 아침 **이메일 한 통**으로 전날 주요 동향을 파악하고,  
필요할 때 **웹 대시보드**에서 심층 검색·분석을 수행합니다.

---

## 시스템이 해주는 것

### 매일 자동으로
- 오전 9시: Google Alerts RSS + 네이버 뉴스 API에서 최신 기사 수집
- ICT/통신 분야 관련도 AI 필터링 → DB 저장
- 기사별 AI 분석(요약 · 키워드 · 시사점) 자동 실행
- 단별 관심 분야 맞춤 보고서 → Gmail 발송 + Google Docs 저장

### 매주 자동으로
- 월요일 오전 9시: 지난 7일 핵심 이슈·트렌드 종합 주간 리포트 발송

### 언제든지 (웹 대시보드)
- 수집된 기사 검색 및 AI 분석 결과 열람
- 자연어 질문 → AI 답변 (RAG 기반)
- 기업·기술·국가 간 연관 관계 지식 그래프 탐색
- 급등 키워드 실시간 알림 확인

## 타 본부 활용 시나리오

이 시스템은 특정 분야의 뉴스를 모니터링해야 하는 **모든 팀**에서 활용할 수 있습니다.

| 본부/팀 | 모니터링 분야 예시 |
|---------|-----------------|
| 융합기술본부 | AI, 빅데이터, 클라우드, IoT |
| 정보통신미디어본부 | OTT, 디지털미디어, 방송통신 |
| 사이버보안본부 | 사이버 위협, 보안 취약점, 인증 |
| 스마트교통물류본부 | 자율주행, 스마트물류, C-ITS |
| 바이오헬스본부 | 디지털헬스, 의료기기, 원격진료 |

> **핵심**: `data/config.json`의 키워드·RSS 목록만 바꾸면  
> 어떤 분야든 동일한 시스템으로 모니터링할 수 있습니다.

## 기술 스택 한눈에 보기

운영에 필요한 외부 서비스는 모두 **무료 플랜**으로 시작할 수 있습니다.

| 역할 | 서비스 | 비용 |
|------|--------|------|
| 코드 저장 + 실행 | GitHub (Actions) | 무료 (월 2,000분) |
| 데이터베이스 | Supabase | 무료 (500MB) |
| 스케줄러 | cron-job.org | 무료 |
| 뉴스 수집 | Google Alerts RSS | 무료 |
| 뉴스 수집 | 네이버 오픈 API | 무료 (일 25,000건) |
| AI 분석 | OpenAI API | 사용량 과금 (소량 저렴) |
| 이메일 발송 | Gmail (앱 비밀번호) | 무료 |
| 결과 저장 | Google Drive + Docs | 무료 (15GB) |
| 웹 대시보드 | Streamlit Community Cloud | 무료 |

> **예상 월 운영비**: OpenAI API 사용료 약 5,000~20,000원 (수집 기사 수에 따라 다름)
