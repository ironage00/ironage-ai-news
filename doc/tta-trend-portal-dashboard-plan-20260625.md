## 사전 필수 — 데이터 품질 확인 (Feature 3 전에 반드시 실행)

Feature 3-6이 모두 `extracted_keywords` JSON에 의존한다. 구현 전 현황 파악 필수.

```python
# Streamlit QA 탭 또는 별도 스크립트에서 실행
SELECT
  COUNT(*) AS total,
  COUNT(CASE WHEN extracted_keywords IS NOT NULL THEN 1 END) AS has_json,
  COUNT(CASE WHEN extracted_keywords::text LIKE '%impact_level%' THEN 1 END) AS has_impact_level,
  COUNT(CASE WHEN extracted_keywords::text LIKE '%target_countries%' THEN 1 END) AS has_countries,
  COUNT(CASE WHEN extracted_keywords::text LIKE '%tta_action_item%' THEN 1 END) AS has_tta_action
FROM news_articles
WHERE is_analyzed = TRUE;
```

**합격 기준**: `is_analyzed=TRUE` 기사 중 80% 이상이 `impact_level`, `target_countries`, `tta_action_item` 보유.
**불합격 시**: `news_engine.py`의 분析 프롬프트를 확인하고 기존 분析 기사를 재분析할지 결정.

**구현** (radar_utils.py에 신규 함수) — **[ENG REVIEW] `keyword_items()` 재사용 (DRY)**:

기존 `keyword_items(row)`(radar_utils.py:313)가 이미 `(이름, 구분)` 튜플을 추출하고 `KEYWORD_FIELDS`에 `target_countries`→"국가", `related_companies`→"기업"이 매핑되어 있으며 str→list 가드도 내장. 재파싱 대신 이를 재사용한다.

```python
@st.cache_data(ttl=7200)
def country_matrix(_engine, days: int = 90, unit_id: int | None = None) -> pd.DataFrame:
    """국가별 기사 수 집계. _engine prefix로 해시 방지.
    keyword_items() 재사용 — 구분='국가'만 필터링."""
    df = fetch_articles(_engine, days=days, unit_id=unit_id, analyzed_only=True, limit=3000)
    if df.empty:
        return pd.DataFrame(columns=["country", "count"])
    counter: Counter[str] = Counter()
    for _, row in df.iterrows():
        for name, label in keyword_items(row):   # str→list 가드는 keyword_items 내부에서 처리됨
            if label == "국가":
                normalized = COUNTRY_NORMALIZE.get(name, name)
                counter[normalized] += 1
    if not counter:
        return pd.DataFrame(columns=["country", "count"])
    return (
        pd.DataFrame(counter.items(), columns=["country", "count"])
        .sort_values("count", ascending=False)
    )
```
