### 메뉴 구성

대시보드 좌측 사이드바에 6개 메뉴가 있습니다.

```
🏠 홈           — 오늘의 수집 현황 + 팀별 최신 기사
📰 뉴스 현황    — 전체 기사 목록 조회 + 상세 분석 보기
🔍 AI 검색      — 자연어 질문 → AI 답변
📊 인텔리전스   — 키워드 트렌드 + 급등 알림 + 엑셀 다운로드
⚙️ 단별 설정    — 팀별 키워드·이메일·RSS 편집
⚙️ 시스템 설정  — API 키·스케줄·멤버십 관리 (관리자 전용)
```

---

### 🏠 홈

**역할**: 오늘의 수집 현황을 한눈에 파악하고, 팀별 최신 기사를 확인합니다.

**화면 구성**

```
┌─────────────────────────────────────────────────────┐
│  오늘 수집   분석 완료   전체 기사   대기 중           │
│   1,020       847       46,753      173             │
├─────────────────────────────────────────────────────┤
│  [표준기획단] [표준혁신단] [AI융합표준단] [전파네트워크단] │
│                                                     │
│  • 삼성전자 6G 표준 특허 1위 …  (오늘 08:52)          │
│  • ITU-T 신규 권고안 채택 …     (오늘 08:30)          │
└─────────────────────────────────────────────────────┘
```

**사용법**
1. 상단 4개 숫자 카드에서 오늘 수집/분석 현황 확인
2. 팀별 탭 클릭 → 해당 팀 관련 최신 기사 목록 확인
3. 기사 행 클릭 → 상세 AI 분석 결과 팝업 표시
4. (관리자) "🚀 전체 프로세스 실행" 펼치기 → 수동 즉시 실행 가능

> 오늘 수집 건수가 0이면 GitHub Actions 실행 결과를 확인하세요.

---

### 📰 뉴스 현황

**역할**: 수집된 전체 기사를 검색·필터링하고 AI 분석 결과를 열람합니다.

**화면 구성**

```
┌─────────────────────────────────────────────────────┐
│  🔍 키워드 검색: [___________________]               │
│  📅 날짜 필터  🏢 단 필터  📊 상태 필터               │
├─────────────────────────────────────────────────────┤
│  제목                 출처    수집일시    상태         │
│  ─────────────────────────────────────────────────  │
│  ▶ 삼성 6G 특허 …    전자신문  06/11 08:52  분석완료  │
│  ▶ ITU-T 권고안 …   ITU      06/11 08:30  분석완료  │
└─────────────────────────────────────────────────────┘
```

**사용법**
1. 키워드 검색창에 찾고 싶은 단어 입력 (예: `6G`, `보안 취약점`)
2. 날짜 필터로 기간 좁히기
3. 단 필터로 특정 팀 기사만 보기
4. 기사 행 클릭 → 우측에 상세 내용 표시:
   - 원문 링크
   - AI 요약 (200자)
   - 추출 키워드
   - 표준화 시사점
   - 중요도 (HIGH / MEDIUM / LOW)

### 🔍 AI 검색

**역할**: 자연어 질문을 입력하면 DB에서 관련 기사를 찾아 AI가 종합 답변을 생성합니다.

**화면 구성**

```
┌─────────────────────────────────────────────────────┐
│  🏢 검색 범위 (단 필터): [전체 ▼]                    │
│                                                     │
│  검색 질문:                                         │
│  [                                             ]   │
│  [ 🔎 AI 검색 ]                                     │
└─────────────────────────────────────────────────────┘
```

**사용법**
1. 검색 범위 선택: 전체 DB 또는 특정 팀 기사만
2. 질문 입력 예시:
   - `"6G 표준화 관련 최신 동향을 알려줘"`
   - `"삼성전자의 최근 통신 표준 활동은?"`
   - `"ITU에서 승인된 AI 표준 목록을 정리해줘"`
   - `"랜섬웨어 관련 최신 보안 위협은?"`
3. **AI 검색** 버튼 클릭
4. AI가 관련 기사를 찾아 종합 답변 + 참조 기사 목록 제공

**팁**
- 구체적인 질문일수록 정확한 답변
- 날짜 범위를 포함하면 더 정확 ("최근 1개월", "2026년 상반기")
- 답변 하단의 참조 기사 링크로 원문 확인 가능

## 3. @tta.or.kr 계정 Google Drive 인증 주의사항

> **TTA 임직원 모두 해당하는 중요 사항입니다.**

### 왜 문제가 되나요?

TTA 임직원의 `@tta.or.kr` 이메일은 Google Workspace(기업용 구글) 계정입니다.  
Google Workspace에서는 조직 관리자가 외부 앱의 접근을 통제합니다.  
이 시스템을 외부 앱으로 등록할 경우, TTA IT 담당자가 별도로 허용하지 않으면  
`@tta.or.kr` 계정으로 OAuth2 인증 시 **"이 앱은 차단되었습니다"** 오류가 발생합니다.

### 권장 해결 방법

**개인 Gmail 계정**(`이름@gmail.com`)으로 OAuth2 인증을 진행합니다.

```
구분          계정
──────────────────────────────────────────
OAuth2 인증   개인 Gmail (@gmail.com)  ← token.json 생성 주체
보고서 수신   @tta.or.kr              ← gmail_receivers에 업무 메일 입력
보고서 열람   @tta.or.kr              ← 이메일 링크 클릭으로 열람
```

### 설정 단계

1. **인증**: `credentials.json` + `token.json`을 **개인 Gmail**로 생성
   ```bash
   # 개인 Gmail 계정으로 인증
   python news_engine.py test
   # 브라우저에서 개인 Gmail 선택 → 허용
   ```

2. **보고서 발송**: `data/config.json`의 수신자는 업무 메일로 설정
   ```json
   "gmail_receivers": [
       "홍길동@tta.or.kr",
       "김철수@tta.or.kr"
   ]
   ```

3. **Drive 접근**: 개인 Gmail 계정의 Google Drive에 보고서 생성됨  
   → 필요시 `@tta.or.kr` 계정과 Drive 폴더 공유 설정

## 4. AI 챗봇을 활용한 장애 해결

시스템 운영 중 오류가 발생했을 때, 프로그래밍 경험이 없어도  
**Gemini, ChatGPT, Claude** 같은 AI 챗봇에 오류 내용을 붙여 넣어 해결 방법을 안내받을 수 있습니다.

### 오류 메시지 복사 방법

**GitHub Actions 오류**
1. GitHub → Actions 탭 → 실패한 실행 클릭
2. `collect` 또는 `report` 클릭
3. 빨간 줄(오류 내용) 드래그하여 복사

**로컬 실행 오류**
```bash
python news_engine.py daily
# 오류가 나면 터미널 전체 내용을 복사
```

**로그 파일에서 확인**
```bash
# PowerShell
Select-String -Path "data\logs\ironage_*.log" -Pattern "ERROR|FAIL" | Select-Object -Last 20
```

### AI 챗봇에 질문하는 방법

아래 형식으로 질문하면 정확한 답변을 받을 수 있습니다.

```
[질문 템플릿]

Python 프로그램을 실행하다가 아래 오류가 발생했습니다.
해결 방법을 단계별로 알려주세요.

=== 오류 내용 ===
(오류 메시지 전체 붙여넣기)

=== 환경 ===
- 운영체제: Windows 11
- Python 버전: 3.11
- 실행 명령: python news_engine.py daily
```

| 챗봇 | 접속 주소 | 특징 |
|------|---------|------|

## 5. 주요 오류 유형별 해결

### 이메일이 오지 않는 경우

1. GitHub Actions 성공 여부 확인 (Actions 탭)
2. 스팸 메일함 확인
3. Gmail 앱 비밀번호 만료 여부 확인
4. 수집 기사 0건 여부 확인

### GitHub Actions 실패

| 오류 메시지 | 원인 | 해결 |
|------------|------|------|
| `No DATABASE_URL` | Secrets 미등록 | Settings → Secrets 확인 |
| `insufficient_quota` | OpenAI 크레딧 소진 | platform.openai.com/billing 에서 충전 |
| `RefreshError: Token expired` | Google 토큰 만료 | token.json 재생성 → Secret 갱신 |
| `Connection refused: Supabase` | Supabase 프로젝트 정지 | supabase.com → Resume project |
| `Naver API rate limit` | 네이버 일일 한도 초과 | 다음 날 자동 초기화 |

### Supabase 프로젝트 정지

무료 플랜은 7일간 미접속 시 자동 정지됩니다.

```
해결:
1. https://supabase.com 접속 → 내 프로젝트
2. "This project is paused" 표시 확인
3. "Resume project" 클릭 → 재시작 (약 1분 소요)
4. GitHub Actions 재실행
```

### 수집 기사 수가 갑자기 줄어든 경우

```
점검 순서:
1. 네이버 API 콘솔(developers.naver.com)에서 한도 확인
2. Google Alerts RSS URL이 만료되지 않았는지 확인
   (6개월 이상 된 RSS는 갱신 필요)
3. 키워드가 현재 뉴스 트렌드와 맞지 않는 경우 → 키워드 업데이트
```

## 6. Supabase DB 직접 확인

수집 현황을 DB에서 직접 확인하고 싶을 때:

1. https://supabase.com → 프로젝트 클릭
2. 좌측 **SQL Editor** 클릭
3. 아래 쿼리 실행:

```sql
-- 오늘 수집 기사 수
SELECT COUNT(*) FROM news_articles
WHERE collected_at >= CURRENT_DATE;

-- 최신 기사 10건
SELECT title, source, collected_at
FROM news_articles
ORDER BY collected_at DESC
LIMIT 10;
```

## 7. 자주 묻는 질문 (FAQ)

**Q. 주말에도 뉴스가 수집되나요?**  
A. 기본 설정은 매일 실행됩니다. 평일만 원하면 cron 표현식을 `0 0 * * 1-5`로 변경.

**Q. 이메일 수신자를 추가하려면?**  
A. `data/config.json`의 `gmail_receivers` 배열에 추가하거나,  
대시보드 ⚙️ 단별 설정에서 직접 편집합니다.

**Q. 리포트를 즉시 받고 싶어요.**  
A. 대시보드 🏠 홈 → "🚀 전체 프로세스 실행" 펼치기 → 실행  
또는 로컬에서 `python news_engine.py daily` 실행.

**Q. Google Docs 보고서가 어디에 저장되나요?**  
A. 인증에 사용한 Gmail 계정의 Google Drive → `99_일일동향` 폴더.

**Q. @tta.or.kr 계정으로 인증이 안 돼요.**  
A. 05_부서별_맞춤설정.md의 '@tta.or.kr 계정과 Google Drive 연동' 섹션 참조.  
개인 Gmail(@gmail.com)로 OAuth2 인증을 진행하세요.

**Q. 오류가 나는데 어떻게 해야 하나요?**  
A. 오류 메시지를 복사해서 Gemini(gemini.google.com) 또는 ChatGPT에 붙여 넣고  
"이 오류의 해결 방법을 단계별로 알려주세요" 라고 질문하세요.  
대부분의 오류는 AI 챗봇이 정확한 해결 방법을 제시해 줍니다.

**Q. 로컬 PC를 꺼도 시스템이 돌아가나요?**  
A. 네. 클라우드(GitHub Actions + Supabase)에서 모두 실행됩니다.

**Q. 월 비용이 얼마나 되나요?**  
A. OpenAI API 비용 외에는 무료입니다. 월 약 5,000~15,000원 수준.
