# 보고서 보관함 페이지 문구

## 페이지 제목

```text
보고서 보관함
```

## 설명

```text
주간·월간 ICT 동향 보고서와 Excel 누적표를 한 곳에서 확인합니다.
Google Docs는 보고서 열람과 공유용, Excel은 기사 목록 검토와 감사용으로 사용합니다.
```

## 섹션

```text
주간 보고서
최근 주간 ICT 동향 및 표준화 시사점

월간 보고서
월간 핵심 이슈, 기술 클러스터, 표준화 대응 과제

Excel 누적표
분석 기사 목록, 키워드 요약, 출처·날짜·링크

자율 인텔리전스 보고서
급등 엔티티와 RAG 기반 자동 분석 결과
```

## 운영 원칙

```text
Supabase를 데이터 원장으로 유지하고, Google Docs와 Excel은 직원 열람용 산출물로 사용합니다.
```
