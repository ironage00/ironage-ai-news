# 활용 가이드 페이지 문구

## 페이지 제목

```text
활용 가이드
```

## 검색 방식 안내

```text
정확한 조건 검색
날짜, 출처, 단, 키워드를 기준으로 기사를 찾습니다.

RAG 검색
자연어 질문과 의미적으로 가까운 기사들을 찾아 근거 기반 답변을 생성합니다.

이슈 맵
기업, 기술, 국가가 어떤 관계로 함께 등장하는지 확인합니다.

GraphRAG
개별 기사보다 큰 흐름, 기술 클러스터, 표준화 대응 과제를 분석합니다.
```

## 좋은 질문 예시

```text
최근 90일간 AI-RAN과 Open RAN이 함께 언급된 기사 흐름을 설명해줘.

NTN 관련 이슈 중 전파네트워크단이 검토해야 할 과제를 정리해줘.

6G 국제표준 경쟁에서 국내 기업이 언급된 사례를 찾아줘.

최근 급등한 기술 키워드와 표준화 시사점을 요약해줘.
```
