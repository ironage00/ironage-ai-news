# 사이트맵

## 홈

목적: 직원이 들어오자마자 오늘 확인해야 할 ICT/표준화 이슈를 파악합니다.

구성:

```text
오늘의 ICT 레이더
이번 주 핵심 이슈
단별 추천 이슈
AI 검색 / 보고서 / 이슈맵 바로가기
```

## AI 검색

목적: 기존 뉴스 DB를 자연어로 검색하고 근거 기반 답변을 확인합니다.

구성:

```text
AI 검색 대시보드 임베드 또는 버튼 링크
검색 예시
결과 해석 방법
```

## 이슈 맵

목적: 기술, 기업, 국가, 표준화 키워드의 관계를 파악합니다.

구성:

```text
주요 엔티티
공출현 관계
GraphRAG 요약
기술 클러스터
```

## 보고서 보관함

목적: 주간/월간 Google Docs 및 Excel 누적표를 한 곳에서 접근합니다.

구성:

```text
주간 보고서
월간 보고서
일일/주간 Excel
키워드 요약표
```

## 활용 가이드

목적: 직원들이 어떤 질문을 해야 하는지 안내합니다.

구성:

```text
검색 예시
단별 활용법
RAG/GraphRAG 차이
보고서 활용 방법
```

## 운영 현황

목적: 데이터 적재, 임베딩, 보고서 생성 상태를 운영자가 확인합니다.

구성:

```text
전체 기사 수
분석 완료 수
임베딩 수
최근 수집 시각
최근 보고서 생성 시각
```
