# 홈 페이지 문구

## 페이지 제목

```text
TTA ICT Trend Radar
```

## 상단 설명

```text
ICT·통신 분야 뉴스와 표준화 이슈를 한 곳에서 확인하는 TTA 내부 인텔리전스 포털입니다.
수집된 뉴스, AI 분석 결과, 주간·월간 보고서, 기술·기업·국가 관계 분석을 업무 목적에 맞게 제공합니다.
```

## 오늘의 레이더 섹션

```text
오늘의 ICT 레이더

최근 수집·분석된 뉴스에서 급등한 기술, 새롭게 등장한 기업·국가, 표준화 검토가 필요한 이슈를 요약합니다.
```

카드 예시:

```text
급등 기술
AI-RAN, NTN, 6G, 위성통신 등 최근 증가한 기술 키워드

표준화 검토 후보
TTA 단별로 검토가 필요한 정책·기술·시장 이슈

보고서 바로가기
주간 보고서, 월간 보고서, Excel 누적표
```
