# 홈 페이지 문구

## 페이지 제목

```text
TTA Intelligence Radar
```

## 상단 설명

```text
오늘의 ICT 표준화 신호를 한 화면에서 읽는 TTA 내부 인텔리전스 포털입니다.
뉴스 원장, AI 분석 결과, 표준화 대응 후보, 관계 맵, 주간 보고서를 연결해 직원이 바로 판단할 수 있도록 제공합니다.
```

## 오늘의 레이더 섹션

```text
오늘의 Intelligence Radar

최근 수집·분석된 뉴스에서 급등한 기술, 새롭게 등장한 기업·국가, 표준화 검토가 필요한 이슈를 요약합니다.
영향도와 긴급도를 기준으로 담당 단이 검토할 후보를 빠르게 찾습니다.
```

카드 예시:

```text
급등 기술
AI-RAN, NTN, 6G, 위성통신 등 최근 증가한 기술 키워드

표준화 검토 후보
TTA 단별로 검토가 필요한 정책·기술·시장 이슈

보고서 바로가기
주간 보고서, 월간 보고서, Excel 누적표
```
