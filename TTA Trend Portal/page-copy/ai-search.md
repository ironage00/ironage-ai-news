# AI 검색 페이지 문구

## 페이지 제목

```text
AI 뉴스 검색
```

## 설명

```text
자연어 질문으로 기존 ICT 뉴스와 AI 분석 결과를 검색합니다.
답변은 관련 기사, 출처, 발행일, 링크를 근거로 제공합니다.
Google Sites 안에서는 포털 임베드 화면으로 제공되며, 필요하면 새 창에서 전체 화면으로 열 수 있습니다.
```

## 검색 예시

```text
최근 3개월 동안 AI-RAN 관련 표준화 이슈를 정리해줘.

NTN과 위성통신 관련 정책 변화가 TTA에 주는 시사점은?

6G 관련 기사 중 국내 기업과 국제 표준화가 함께 언급된 사례를 찾아줘.

양자통신 관련 주요 국가와 기업의 움직임을 비교해줘.
```

## 안내 문구

```text
검색 결과는 내부 검토용입니다.
중요 의사결정에는 원문 기사와 Google Docs 보고서를 함께 확인하세요.
```

## 버튼 문구

```text
AI 검색 대시보드 열기
```

## 임베드 안내

```text
Google Sites의 Insert → Embed → Embed code 메뉴에서 embeds/streamlit-embed.html 내용을 붙여 넣습니다.
STREAMLIT_URL은 실제 배포된 Streamlit 대시보드 주소로 교체합니다.
Sites 임베드용 주소는 STREAMLIT_URL?embed=1 형식을 사용합니다.
```
