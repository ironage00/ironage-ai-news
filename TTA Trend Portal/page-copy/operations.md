# 운영 현황 페이지 문구

## 페이지 제목

```text
운영 현황
```

## 설명

```text
뉴스 수집, AI 분석, 임베딩, 보고서 생성 상태를 확인합니다.
운영 담당자는 이 화면을 통해 데이터 누락과 검색 품질 문제를 점검합니다.
```

## 점검 항목

```text
전체 기사 수
분석 완료 기사 수
임베딩 완료 기사 수
임베딩 누락 기사 수
최근 수집 시각
최근 Google Docs 보고서 생성 시각
최근 Excel 업데이트 시각
최근 GitHub Actions 실행 결과
```

## 권장 운영 기준

```text
임베딩 누락이 많으면 배치 임베딩 실행
Google Drive 보고서 누락 시 report_artifacts 대조
검색 결과가 부족하면 기간 필터와 분석 완료 여부 확인
```
